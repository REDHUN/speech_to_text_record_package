# speechtotextrecord Example

This example demonstrates how to use the `speechtotextrecord` Flutter plugin on Android.

## Features demonstrated

- Runtime microphone permission request and status check.
- Speech recognition service availability check.
- Live microphone peak amplitude visualization.
- Real-time partial & committed speech transcription.
- Recording to a standard 16 kHz mono WAV file.
- Language/locale selection (`en-US`, `en-IN`, `hi-IN`, `ml-IN`, etc.).
- Optional on-device recognition toggle.
- Safe cancellation and clean file deletion.

## Running the Example

Run from the root of `speechtotextrecord`:

```bash
cd example
flutter run
```
